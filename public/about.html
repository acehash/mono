Mono

极简个人记账 PWA — 开发者部署指南

项目概览

Mono 是一款极简风格的个人记账 Web 应用，采用手绘笔记本设计语言（sketch design），支持 PWA 安装到手机桌面，可离线使用。

技术栈

Next.js 14 React 18 TypeScript Tailwind CSS Supabase Recharts

核心特性

PWA 邮箱登录 收支分类 统计图表 手绘风格

功能模块

页面路径说明
首页/本月结余、收入/支出汇总、最大三笔支出
流水/records按月查看记录，支持全部/支出/收入筛选，左滑编辑/删除
统计/stats收支折线图（近半年）、支出/收入饼图、分类排行
记一笔首页 FAB数字键盘输入金额、选择分类、日期时间、备注
登录/login邮箱 Magic Link 登录（Supabase Auth）

数据库设计

使用 Supabase 作为后端（PostgreSQL + Auth + RLS）。

categories 表（分类）

字段类型说明
idUUID主键
user_idUUID (nullable)NULL 表示系统预设分类
typeENUMincome / expense
nameTEXT分类名称（餐饮、交通等）
iconTEXT图标标识
sort_orderINT排序权重

transactions 表（交易记录）

字段类型说明
idUUID主键
user_idUUID关联 auth.users
typeENUMincome / expense
amountDECIMAL(12,2)金额（必须 > 0）
category_idUUID (FK)关联 categories
noteTEXT (nullable)备注
dateDATE交易日期
created_atTIMESTAMPTZ创建时间

部署步骤

1. 环境准备

  • Node.js >= 18
  • npm 或 yarn
  • Supabase 项目（免费层即可）

2. 创建 Supabase 项目

  1. 前往 supabase.com 注册并创建项目
  2. 在 SQL Editor 中执行 supabase/migrations/001_initial.sql 完成建表
  3. 在 Authentication → Providers 中启用 Email 登录
  4. 在 Authentication → URL Configuration 中添加生产域名到 Redirect URLs

3. 配置环境变量

创建 .env.local 文件：

NEXT_PUBLIC_SUPABASE_URL=你的Supabase项目URL
NEXT_PUBLIC_SUPABASE_ANON_KEY=你的Supabase匿名Key

4. 安装与构建

# 安装依赖
npm install

# 本地开发
npm run dev

# 生产构建
npm run build

# 启动生产服务
npm start

5. 部署到 Vercel（推荐）

# 安装 Vercel CLI
npm i -g vercel

# 部署
vercel --prod

在 Vercel 项目设置中添加环境变量：NEXT_PUBLIC_SUPABASE_URL 和 NEXT_PUBLIC_SUPABASE_ANON_KEY。

6. 部署到其他平台

支持任何支持 Node.js 的平台：

  • Docker — 构建镜像后运行 npm start（默认端口 3000）
  • Cloudflare Pages — 需要 @cloudflare/next-on 适配器
  • 自建服务器 — npm run build && npm start

PWA 配置

Mono 已内置 PWA 支持，使用 next-pwa 插件自动生成 Service Worker。

manifest.json

{
  "name": "Mono - 简单记账",
  "short_name": "Mono",
  "display": "standalone",
  "orientation": "portrait",
  "theme_color": "#FFF8F0",
  "background_color": "#FFF8F0",
  "start_url": "/"
}

PWA 图标

在 public/icons/ 目录下放置以下尺寸的 PNG 图标：

  • icon-192.png — 192×192（Android 屏幕）
  • icon-512.png — 512×512（启动画面）

推荐使用 favicon.io 或 PWABuilder 在线生成。

安装行为

  • Android Chrome：地址栏出现"安装应用"提示
  • iOS Safari：点击分享按钮 → "添加到主屏幕"
  • 桌面端：地址栏右侧出现安装图标

安装后应用以独立窗口运行，无浏览器地址栏，支持全屏体验。

设计系统

Mono 采用"手绘笔记本"设计语言，核心元素：

  • 纸质背景 — #F5F0E8 暖纸色 + SVG 噪点纹理
  • 墨水色调 — #2C2416 深棕主色 + 分级灰度
  • 手绘边框 — SVG feTurbulence 滤镜产生微扭曲效果
  • 圆角不规则 — border-radius: 2px 5px 3px 4px 模拟手绘
  • 铅笔阴影 — box-shadow: 2px 3px 0px 硬投影
  • 全局字体 — Inter Variable（支持 tabular-nums 数字等宽）

认证流程

  1. 用户在 /login 输入邮箱
  2. 调用 supabase.auth.signInWithOtp() 发送 Magic Link
  3. 用户点击邮件中的链接
  4. 回调路由 /auth/callback 交换 session
  5. 重定向到首页，middleware.ts 验证 session 保护路由

开发命令

命令说明

注意事项

  • Supabase 免费层限制：500MB 数据库、1GB 文件存储、50000 月活跃用户
  • PWA Service Worker 在开发模式下自动禁用（next.config.mjs 中配置）
  • 数据库 RLS 策略确保用户只能访问自己的数据
  • 分类支持系统预设（user_id = NULL）和用户自定义两类
